# 棘薔薇 -TOGEBARA- ポートフォリオサイト 使い方ガイド

はじめまして。このサイトは、あなたが「イラストレーターとしての世界」を
公開するために作られたポートフォリオサイトです。
プログラミングの知識がなくても、**管理画面から作品を追加・編集・削除**
できるように作られています。

---

## 1. まずは動かしてみる

このフォルダの中の **`index.html`** をダブルクリックすると、
ブラウザ（Chrome や Safari など）でサイトが開きます。

- `index.html` … TOPページ
- `gallery.html` … 作品一覧ページ
- `work.html` … 作品の詳細ページ（ギャラリーから作品をクリックすると開きます）
- `about.html` … プロフィールページ
- `commission.html` … 依頼案内ページ
- `admin.html` … **管理画面**（ここから作品やプロフィールを編集します）

最初はサンプルの作品が4つ入っています。まずはこのまま眺めてみてください。

---

## 2. 管理画面の使い方

`admin.html` を開くと、左側にメニューがあります。

### 作品を追加する
1. 「作品管理」→「＋ 作品を追加」を押す
2. 画像の枠をクリックして、イラストの画像ファイルを選ぶ
3. タイトルと説明を入力する
4. 「公開する」を押す

これだけで、ギャラリーに作品が追加されます。

### 作品を編集・削除する
「作品管理」の一覧で、それぞれの作品の「編集」「削除」ボタンから操作できます。
「▲」「▼」ボタンで、ギャラリーに並ぶ順番を変えられます。

### プロフィール・SNS・依頼情報・サイト設定
左メニューの各項目から、それぞれ編集して「保存する」を押すだけで反映されます。

> 保存すると同時に、公開サイト（index.html など）にもすぐに反映されます。
> `admin.html` で「🔗 サイトを見る」を押すと、別タブで確認できます。

## 3. 「どのファイルを編集すれば何が変わるか」早見表

| 変えたいこと | 編集するファイル |
|---|---|
| 作品・プロフィール・SNS・依頼内容の中身 | `admin.html`（管理画面から） |
| サイト全体の色 | `css/style.css` の一番上、`:root { ... }` の色コード |
| 文字のフォント | `css/style.css` の `:root` にある `--font-display` など |
| TOPページの構成・文章 | `index.html` |
| ギャラリーの見た目 | `gallery.html` / `css/style.css` の `.gallery-grid` 付近 |
| 管理画面の見た目 | `css/admin.css` |
| 管理画面の動き | `js/admin.js` |
| アニメーションの動き | `js/main.js` |

基本的に「文章や作品の中身」は admin.html だけで完結します。
コードを直接触るのは、色やレイアウトを変えたいときだけで大丈夫です。

## 4. データの保存について（とても重要）

現在、このサイトのデータ（作品・プロフィールなど）は、
**あなたが今 admin.html を開いているブラウザの中（localStorage）** に
保存されています。

これは、

- 追加の登録や費用が一切かからない
- 今すぐ、このまま動作確認できる

というメリットがある一方で、

- **別のパソコンやスマホから admin.html を開いても、同じデータは見えません**
- ブラウザの「閲覧データを消去」をすると、内容が消えてしまいます

という注意点があります。個人の確認・練習用としては十分ですが、
**本番として世界に公開する場合は、下の「5. 本番公開について」**
を参考に、どこからでも編集・閲覧できる状態にすることをおすすめします。

---

## 5. 本番公開について（提案）

このサイトは HTML / CSS / JavaScript だけで作られているので、
**無料の静的サイトホスティング**（Netlify、Vercel、GitHub Pages など）に
そのままアップロードするだけで、世界中に公開できます。

ただし「管理画面から更新した内容を、公開後もどこからでも編集したい」
場合は、次のどちらかの方法をおすすめします。

### おすすめA：Firebase（無料枠あり・比較的簡単）
Googleが提供する無料のデータ保存サービスです。
`js/data.js` の中の `getData()` と `saveData()` という2つの関数だけを
Firebaseへの読み書きに書き換えれば、他のファイルは一切変更せずに
「どこからでも同じ作品一覧が見える・編集できる」サイトになります。
（`js/data.js` の冒頭に、その理由をコメントで書いています。）

### おすすめB：Decap CMS（旧Netlify CMS）
GitHub上にデータを保存し、管理画面からの操作でそのままサイトの
更新が反映される仕組みです。エンジニアの手を借りずに設定できる
テンプレートが多数公開されています。

どちらも「無料で始められる」「他人にデータを見られる心配が少ない」
という理由でおすすめしていますが、実際の導入は、詳しい方に相談する
か、Claude などのAIアシスタントに
「このサイトにFirebaseを組み込みたい」と伝えて手伝ってもらうと
スムーズです。

## 6. サンプル画像について

現在、作品に画像を登録していない場合、赤・黒・白を使った
「仮のイラスト」が自動で表示される仕組みになっています
（`js/data.js` の `generatePlaceholderArt` という関数が生成しています）。

これはあくまで仮の画像です。管理画面から実際のイラストをアップロード
すると、自動的にそちらが優先して表示されます。

> 画像はブラウザの中に保存されるため、あまり大きすぎる画像（数十MB）を
> 大量に登録すると、ブラウザの保存容量の上限に達することがあります。
> 目安として、1枚あたり 1〜2MB 程度に圧縮してから登録することをおすすめします。

## 7. 今後、追加しやすい構造にしてあります

- **SNS**：`admin.html` の「SNS」ページにURLを入れるだけで、
  サイト内の該当箇所（TOPページのメニュー、フッターなど）に自動的に
  リンクが表示されます。
- **Commission（依頼受付）**：`admin.html` の「依頼情報」から、
  受付状況やメニューをいつでも書き換えられます。「準備中」の文言を
  変えるだけで、そのまま「受付中」の案内ページとして使えます。
